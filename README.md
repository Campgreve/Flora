## About

Flora was made for the contest *Informatica x Gioco = Fantasia + Regole, Edizione VII*, whose theme is pollution and sustainability (Agenda 2030).

A sudden event sends the protagonist through a passage into a world that looks like ours but has lost its natural balance. Leo travels with the player, offering observations rather than instructions. Each area shows a different kind of damage caused by pollution, and the player has to work out what happened by looking at the environment.

The gameplay mixes exploration, puzzles and boss fights. The project is still in development.

## Controls

| Input | Action |
|---|---|
| Left click (hold, release) | Charge and fire the bow |
| Right click | Aim assist on the enemy |
| E | Interact |
| Space | Dash |
| Tab | HUD stats and map info |
| Alt + Enter | Fullscreen |

PS4/PS5 and Xbox One controllers are supported.

## Install

Download a build from [itch.io](https://matterder.itch.io/flora).

- **Windows:** extract the ZIP and run `Flora.exe`.
- **macOS:** extract the ZIP and open the app. If a security warning appears, choose "Open anyway".

Some antivirus software flags the game as suspicious. This is a false positive; allow it manually if needed.

## Build from source

```bash
git clone https://github.com/Campgreve/Flora.git
```

Open the folder in Unity Hub, let the assets import, then open the main scene and press Play.
